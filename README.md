# Aiburo Bhaat Wedding Invitation

An interactive Bengali wedding invitation built with React, TypeScript, Vite, GSAP, and Tailwind CSS.

## Development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The site is configured for GitHub Pages at <https://chatterjeeritam97-sketch.github.io/shubhamrita/>. Pushing to `main` builds and publishes the `dist` directory with GitHub Actions.
